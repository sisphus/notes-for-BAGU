# 00 — Go 后端面试复习总路线

## 核心能力层级

- 语法层：能快速写出正确 Go 代码。
- Idiomatic Go 层：代码符合 Go 风格，小接口、显式错误、组合优先。
- 并发层：理解 goroutine/channel/sync/context/race。
- 后端工程层：HTTP、DB、Redis、事务、幂等、日志、测试、超时。
- 系统设计层：能设计订单、支付、调度、聊天、文件上传等后端系统。
- 项目表达层：能讲问题、方案、权衡、结果、复盘。

## 总复习顺序

- Go language core
- Data structures and algorithms in Go
- Idiomatic Go design
- Errors and resource management
- Concurrency foundations
- Sync/memory model/race
- Context/timeouts/shutdown
- Testing quality engineering
- Backend standard library
- Database/Redis/transactions
- Runtime/GC/performance
- Tooling/build/deploy
- API service architecture
- System design
- Project stories
