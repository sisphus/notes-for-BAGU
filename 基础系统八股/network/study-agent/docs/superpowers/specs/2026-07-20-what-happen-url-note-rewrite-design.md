# `what_happen_url.md` 整篇重写设计

## 目标

将 `outputs/notes/base/what_happen_url.md` 从多轮局部修补形成的笔记，重写为符合本仓库 `AGENTS.md` 的完整、中文、schema-led 学习笔记。重写必须以 `materials/network/1_base/what_happen_url.md` 为事实来源，保留必要边界说明，但不把正文扩写成通用网络教材。

## 当前问题

- `2.5 路由表` 同时承载局域网、接口、直连、下一跳、IP/MAC、路由来源和逐跳循环，长度明显失衡。
- 路由器相关关系被多个相近图和后续章节重复解释，增加无效认知负荷。
- Core Concepts 的部分小节保留了对话式修补痕迹，没有统一的 Definition、Intuition、Example、Common mistakes 结构。
- 教学过程使用 `客户端 → R1 → R2 → 服务器`，Minimal Working Example 却使用另一组公网地址，导致读者需要重建空间模型。
- 英文模板标题和中文正文混用，风格不统一。

## 采用方案

采用整篇结构性重写，不保留现有段落位置，也不在文末追加修补区。事实正确且有学习价值的内容可以改写后复用；重复图、重复解释和超出当前主线的展开应删除或移入边界说明。

不拆分成多篇笔记：本章问题本身要求把浏览器、协议栈和网络设备串成一条执行链，单篇完整笔记更适合作为面试复习入口。

## 笔记结构

### 1. 主题概览

说明问题范围、学习价值、难度、前置知识和源文件。明确主线是简化的 `HTTP over TCP/IPv4/Ethernet`，并标出 HTTPS、NAT、HTTP/3 和浏览器渲染属于边界。

### 2. 核心概念

按原文执行顺序组织九个可运行 schema：

1. 从 URL 提取协议、目标与资源。
2. 用 DNS 缓存链和分层委派得到目标 IP。
3. 让上层委托下层，并在发送端封装、接收端解封装。
4. 用 TCP 连接状态和序号/确认机制承载可靠字节流。
5. 用目标 IP 匹配路由表，得到出接口和下一跳。
6. 用 ARP 将当前下一跳 IP 转换成当前链路 MAC。
7. 让交换机学习 `源 MAC → 入端口`，再按 `目标 MAC → 出端口` 转发。
8. 让每台路由器重复“拆旧帧、查目标 IP、选下一跳、造新帧”。
9. 让目标主机按 MAC、IP、协议号、端口逐层交付给 Web 服务，再生成响应。

每个 schema 固定包含 Definition、Intuition、Example、Common mistakes。前置桥只放在使用它的 schema 内，并压缩为完成当前任务所需的最小范围。

### 3. 深入理解

集中解释跨 schema 关系，避免在 Core Concepts 中反复展开：

- 最终目标 IP 与当前下一跳 MAC 的区别。
- 下一跳正确依赖路由表与真实拓扑一致。
- DNS 缓存、路由表、ARP 缓存、交换机 MAC 表的键值与作用范围。
- 交换机二层原样转发与路由器三层重封装的区别。
- HTTPS、NAT、连接复用、非对称路由和浏览器渲染边界。

### 4. 最小工作示例

全文统一使用一组拓扑：

```text
客户端 192.168.1.10
  → R1: 192.168.1.1 / 192.168.2.1
  → R2: 192.168.2.2 / 192.168.3.1
  → 服务器 192.168.3.50
```

示例从 URL 和 DNS 开始，经过 TCP/IP/以太网封装，明确列出三跳的目标 IP 和目标 MAC，再以服务器解封装和 HTTP 响应结束。该拓扑只用于解释机制，明确省略 NAT。

### 5. 章节知识地图

保留一张 10–15 节点的 Mermaid 图，仅表达 depends on、is used in、is part of 和 transfers to 等允许关系。

### 6. 自测题

提供 3 道回忆题、2 道迁移题和 1 道五岁解释题，不直接附答案。

### 7. 薄弱点检测

使用表格映射典型错误表现、对应 schema、错误类型和最小检查问题。包含本轮真实出现的“下一跳为何正确”和“交换机如何按 MAC 选择端口”边界。

## 可视化设计

只保留四张概念局部图和一张章节地图：

1. DNS 缓存短路与分层查询。
2. HTTP 数据在 TCP、IP、Ethernet 中的封装。
3. `客户端 → R1 → R2 → 服务器` 的逐跳 IP/MAC 变化。
4. 交换机的源 MAC 学习、目标 MAC 查表和未知目标泛洪。
5. 章节知识地图。

每张局部图必须紧邻所解释的 Example，包含 How to read、Source anchor 和必要的 Boundary。所有 Mermaid 必须实际用 `mmdc` 渲染成功。
